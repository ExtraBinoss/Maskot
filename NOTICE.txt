# Provenance et licences

MascotLab porte en React l’atelier de mascottes de [Beam](https://github.com/BeamRecorder/Beam).
Le modèle, la validation, l’export, le lecteur, le rendu SVG et l’organisation des contrôles
proviennent de `apps/desktop/src/components/brand/lab/` et `brand/Beamy/BeamySvg.vue`.
Les adaptations de ces sources sont distribuées sous MPL-2.0, dont le texte est conservé dans `LICENSE`.

Le moteur dans `src/mascot/engine/` et ses tests proviennent de Beam et adaptent
[Bloub](https://github.com/jeremy-prt/bloub), par Jérémy Perret (MIT).
Les notices et le texte MIT d’origine sont conservés dans ce dossier.
Les fichiers du moteur ont été repris sans changement de comportement.

La configuration React, les tokens de thème et le bouton shadcn/Base UI suivent le hub Plinka.
Space Grotesk et Source Sans 3 sont servis localement via leurs packages Fontsource,
avec leurs licences OFL fournies dans les dépendances.

Le code source de MascotLab est disponible sur https://github.com/ExtraBinoss/MascotLab.
